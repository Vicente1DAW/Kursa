# Documentación del backend

El backend es una API Express con TypeScript, PostgreSQL y Socket.IO. Las funciones disponibles y sus límites se detallan en la referencia de API; que exista soporte Socket.IO en el servidor no implica que la videollamada del frontend esté terminada.
